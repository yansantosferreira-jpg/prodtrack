# ProdTrack

Painel de produtividade desenvolvido com HTML, CSS e JavaScript.

## Sobre o projeto

O ProdTrack é uma aplicação web para calcular e acompanhar indicadores de produtividade a partir da produção realizada, das horas trabalhadas e de uma meta definida.

O projeto foi desenvolvido para praticar fundamentos de desenvolvimento web e manipulação de dados no navegador.

## Funcionalidades

- Cálculo de produtividade por hora.
- Cálculo do percentual de atingimento da meta.
- Validação dos dados informados.
- Histórico de cálculos.
- Armazenamento local dos registros com `localStorage`.
- Exibição dos registros mais recentes primeiro.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute um servidor HTTP local, como `python -m http.server 8000`.
4. Acesse `http://localhost:8000` no navegador.

## Objetivo

Desenvolver habilidades práticas em JavaScript, lógica de programação, manipulação do DOM e armazenamento de dados.

## Observação

Os dados são armazenados localmente no navegador. Não existe banco de dados ou sincronização entre dispositivos nesta versão.
